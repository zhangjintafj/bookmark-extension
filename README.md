# Google Sheet 书签同步助手 (Browser Bookmark to Google Sheets)

一款功能强大、现代易用的浏览器扩展程序（支持 Chrome、Edge、Brave、Firefox 等所有 Chromium 浏览器）。它可以帮助您**一键将当前网页以书签形式存入指定的 Google Sheet**，并支持**通过浏览器导出的 HTML 书签文件批量导入，且完整保持多级目录分组与原生折叠结构**。

---

## 🌟 核心功能特色

1. **一键存入当前网页（极速高效）**
   - 自动提取当前活动标签页的网页标题与网址 (URL)。
   - **智能读取已有工作表与分组**：自动从 Google 表格中动态读取现有的工作表列表与分类目录，下拉菜单即开即选。
   - **新建选项置顶第一项**：在「目标工作表」和「分组目录」下拉菜单中，【➕ 新建...】永久置顶在第 1 项，即使目录再多也无需滑到底部查找，点击即可输入新名称，并支持 `✕` 一键取消还原。
   - 界面清爽简洁，聚焦书签标题、网址、目标工作表、分组目录与备注说明。
   - 支持网页右键菜单快捷存入当前页面或网页上的特定超链接。

2. **批量导入本地书签 HTML 文件**
   - 兼容 Chrome、Edge、Firefox、Safari 等导出的 Netscape Bookmark HTML 格式文件。
   - 毫秒级解析多级目录树，支持层级折叠预览、书签总数与各层级目录统计。
   - 采用分批异步队列上传机制，带有实时进度条，几百上千条书签顺畅导入。

3. **完美保持目录分组与原生折叠（两种呈现模式）**
   - 🌳 **原生层级大纲折叠树（默认推荐）**：
     - 单条存入和批量导入统一采用 4 列大纲标准结构：`[ 📁 目录层级 / 书签名称 | 🔗 链接 URL | 📅 添加时间 | 📝 备注 ]`。
     - 文件夹行加粗突出，子书签自动缩进，并在 Google Sheet 侧边自动创建 **Google 电子表格原生折叠分组（Row Groups `[-]` `[+]`）**。
     - **严格同级收拢**：无论单条追加还是新建立分组，所有书签统一收拢在所属目录的第 1 层折叠组中，杜绝逐级递增阶梯式折叠；保存新书签时还会自动扫描并修复该目录下此前未分组的历史书签。
   - 📊 **标准多维表格**：以完整路径、一级分类、书签超链接、URL、备注、添加时间等多列平铺展示，便于使用 Filter 筛选和数据透视分析。

4. **智能查重防重复**
   - 自动检测目标 Google Sheet 中已存在的 URL，避免重复添加，并提示已有书签所在的行数和直达链接。

5. **极简部署，无需复杂 OAuth 审核**
   - 采用 Google Apps Script (GAS) Web App 作为轻量安全的云端接收端，完全免费，无须申请 GCP 控制台凭证，任何普通 Google 账号 1 分钟即可部署完毕！

## 🚀 快速上手教程（只需 2 步）

### 第一步：在 Google Sheet 中配置 Apps Script（约 1 分钟）

1. **新建 Google 电子表格**：
   - 浏览器打开 [sheets.new](https://sheets.new) 创建一个新的 Google 表格（可命名为例如 `我的网络书签`）。
2. **打开脚本编辑器**：
   - 在表格上方菜单栏点击：**「扩展程序 (Extensions)」** ➔ **「Apps Script」**。
3. **粘贴后端代码**：
   - 清空编辑器里的原有内容，打开本项目的 `google-apps-script/Code.gs` 文件，复制其中的全部代码并粘贴进去。
   - 点击保存（Ctrl + S / Cmd + S）。
4. **部署为 Web 应用（关键）**：
   - 点击右上角蓝色的 **「部署 (Deploy)」** ➔ **「新建部署 (New deployment)」**。
   - 点击左侧齿轮图标，选择 **「Web 应用 (Web app)」**。
   - 设置以下三个选项：
     - **说明**：`书签同步服务`
     - **执行身份 (Execute as)**：选择 **`我 (Me / 您的邮箱)`**
     - **访问权限 (Who has access)**：选择 **`任何人 (Anyone)`** *(确保浏览器插件能够向该脚本发送书签数据)*
   - 点击右下角的 **「部署」**。
   - *(首次部署会弹出权限提示，点击「授予访问权限」，选择您的 Google 账号，点击「高级 (Advanced)」➔「转到未命名的项目(不安全)」，然后点击「允许」)*。
5. **获取 Web App URL**：
   - 部署完成后，界面会展示一个以 `https://script.google.com/macros/s/.../exec` 结尾的 **Web 应用网址**，点击 **「复制」** 保存备用。

> 💡 **后续更新代码须知**：修改了 `Code.gs` 之后，需要点击右上角 **「部署」➔「管理部署」➔ 点击编辑(铅笔图标) ➔ 版本下拉框选择「新版本 (New version)」➔ 点击「部署」**，新代码才会生效。

---

### 第二步：安装并配置浏览器插件

1. **加载扩展程序到浏览器**：
   - 打开 Chrome 或 Edge 浏览器，在地址栏输入：`chrome://extensions/` 并回车。
   - 打开右上角的 **「开发者模式 (Developer mode)」** 开关。
   - 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」** 按钮。
   - 选择本项目的根目录文件夹（即包含 `manifest.json` 的目录）。
   - 此时浏览器工具栏将出现 **Google Sheet 书签同步助手** 图标。
2. **配置接口地址**：
   - 点击插件图标，在弹出的窗口右上角点击 ⚙️ **「设置」** 图标（或在扩展管理页点击「详细信息」➔「扩展程序选项」）。
   - 在 **「Google Apps Script Web App URL」** 输入框中，粘贴在第一步复制的 Web 应用网址。
   - 点击 **「⚡ 测试接口连通性」** 按钮，若提示 `✅ Google Sheets 连接成功！`，点击 **「💾 保存设置」** 即可！

## 📖 使用指南

### 1. 收藏当前网页到 Google Sheet
- 浏览任何网页时，点击浏览器右上角的插件图标。
- 弹窗会自动填充当前网页的标题和 URL。
- **目标工作表**：下拉直接选择已有的工作表，或选择置顶的 `➕ 新建工作表...` 输入新表名（支持点击 🔄 按钮手动刷新表格列表）。
- **分组目录**：下拉直接选择表格中已有的分类（如 `开发/前端`），或选择置顶的 `➕ 新建目录...` 输入新目录名称。
- 可选填备注说明，点击 **「存入 Google Sheet」** 即可瞬间保存！
- 亦可在任何网页空白处或超链接上点击鼠标右键，选择 **「📑 存入当前页面到 Google Sheet」** 进行极速保存。

### 2. 通过 HTML 书签文件批量导入并保持目录分组
- 在 Chrome/Edge 浏览器按快捷键 `Ctrl + Shift + O`（Mac 为 `Cmd + Option + B`）打开书签管理器。
- 点击右上角菜单「⋮」➔ **「导出书签」**，保存为 `bookmarks.html` 文件。
- 打开插件，点击顶部导入图标（或点击弹窗底部的「📂 批量导入本地书签 HTML 文件」）。
- 将 `bookmarks.html` 文件拖拽至上传区域。
- 插件将秒级解析出目录树结构与统计数据，您可以在页面上预览目录树。
- 选择您喜欢的目录呈现方式：
  - **🌳 原生层级大纲折叠树**：在 Google Sheet 中会为每个文件夹创建高亮标题行，子书签自动缩进，并建立原生折叠分组 `[-]`/`[+]`！
  - **📊 标准多维表格**：以完整路径、各级分类列平铺展示。
- 点击 **「🚀 开始导入到 Google Sheet」**，查看实时进度条完成同步。
- 导入完成后，点击结果卡片上的 **「在 Google Sheet 中查看书签 ↗」** 即可直达您的表格！
