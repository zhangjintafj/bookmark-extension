# Google Sheet 书签同步助手

将正在浏览的网页一键存入指定的 Google Sheet，支持直接导入本地 HTML 书签文件并保持多级目录分组与原生折叠大纲结构。

---

## 🌟 核心功能

1. **一键存入当前网页**：点击插件图标或网页右键菜单，秒级保存标题、URL、分组目录、备注与标签。
2. **HTML 书签批量导入**：支持从 Chrome / Edge 导出的 `bookmarks.html` 批量导入。
3. **保持多级目录分组**：
   - 🌳 **原生大纲折叠树**：在 Google Sheet 侧边自动生成原生折叠行组 `[-]` `[+]`。
   - 📊 **标准多维表格**：以完整路径、各级分类列平铺展示。
4. **自动查重**：防止重复添加相同网址。

---

## 🚀 部署步骤

### 第一步：配置 Google Sheet Apps Script

1. 浏览器打开 [sheets.new](https://sheets.new) 新建一个 Google 表格。
2. 点击菜单 **「扩展程序 (Extensions)」➔「Apps Script」**。
3. 清空原有内容，将项目中的 `google-apps-script/Code.gs` 代码复制进去并保存（Ctrl+S）。
4. 点击右上角蓝色 **「部署」➔「新建部署」**。
5. 齿轮类型选择 **「Web 应用 (Web app)」**：
   - 说明：`书签同步`
   - 执行身份：`我 (Me)`
   - 访问权限：**`任何人 (Anyone)`**（重要：保证插件可跨域提交）
6. 点击「部署」，在弹出的授权窗口中允许访问。
7. 复制生成的以 `https://script.google.com/macros/s/.../exec` 结尾的 Web App URL。

### 第二步：安装并配置浏览器插件

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
2. 打开右上角 **「开发者模式」** 开关。
3. 点击左上角 **「加载已解压的扩展程序」**，选择包含 `manifest.json` 的本插件根目录。
4. 点击插件图标 ➔ 右上角 ⚙️ **「设置」**。
5. 粘贴上一步复制的 Web App URL，点击 **「⚡ 测试接口连通性」**，提示成功后点击 **「💾 保存设置」**。

## 📖 使用说明

- **保存当前网页**：浏览网页时点击插件图标，选择或输入分组（如 `工作/常用`），点击「存入 Google Sheet」。
- **批量导入 HTML 书签**：
  1. 在 Chrome 书签管理器按 `Ctrl+Shift+O` ➔ 导出书签为 `bookmarks.html`。
  2. 点击插件上的「批量导入本地书签 HTML 文件」。
  3. 拖入 HTML 文件，选择「原生层级大纲折叠树」，点击「开始导入到 Google Sheet」。
